# Lekker AI Visualiser — Demo Film

25-second product film for the Lekker AI wallpaper visualiser.

## Main files

- `index.html` — master visual/motion source.
- `render.py` — renders the HTML timeline to stills or MP4.
- `tools/build_assets.py` — prepares the photoreal room plates, masks and derived assets.
- `assets/` — source imagery, wallpaper swatches and local audio.
- `docs/` — storyboard/keyframes and project notes.
- `output/` — final deliverables.
- `archive/` — intentionally retained legacy versions only.

## Naming rules

Use lowercase kebab-case. Name by purpose, not by app/export history.

Good: `room-botanical.png`, `storyboard-keyframes.jpg`, `lekker-ai-visualiser-final.mp4`

Avoid: `final-final-2.mp4`, `index-opus-final.html`, `ChatGPT Image Oct 6....png`

Git already provides version history, so duplicate source snapshots do not need to live beside the active source.

## Local render

```bash
.venv/bin/python render.py --stills 6.8,12.8,15.5,18.5,20.5
.venv/bin/python render.py --out output/lekker-ai-visualiser-final.mp4
```

## Music

The soundtrack is **Holding Back — Duckmaw (Epidemic Sound)**.

Do **not** commit the raw licensed MP3 to this public repository. Keep it locally at:

```text
assets/audio/holding-back.mp3
```

The current preferred sync uses a source in-point around `13.186s`; preserve the locked visual timing and trim/offset the music instead.

## Before considering the repo complete

The repo should contain the master source, renderer, asset-builder script, all 16 source visual assets, storyboard/keyframes, and one clearly labelled final MP4. Generated stills, frame sequences, virtual environments and raw licensed music should stay out of Git.
